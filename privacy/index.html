전축은 이용자의 개인정보를 수집하지 않습니다. 회원가입·로그인이 없고, 데이터를 받는 서버가 없으며, 광고와 추적 기술도 없습니다. 앱에 인터넷 권한 자체가 없어 어떤 데이터도 기기 밖으로 나가지 않습니다.

1. 수집하는 개인정보

없습니다. 사업자(Vravio Inc)는 어떠한 개인정보도 수집·전송·판매·공유하지 않습니다. 앱은 인터넷 권한(INTERNET)을 선언하지 않으므로 운영체제 수준에서 네트워크 통신이 차단되어 있습니다.

2. 기기 내부에서 읽고 저장하는 정보

전축은 이용자가 기기에 넣어 둔 음악 파일을 재생하는 플레이어이며, 음원을 제공하지 않습니다.

  • 읽기 — 기기의 음악 파일 목록과 곡 정보(제목·가수·앨범·길이·폴더·앨범 커버)를 안드로이드 미디어 저장소에서 읽어 화면에 보여 주고 재생합니다. 파일을 수정·삭제·복사하지 않습니다.
  • 저장 — 즐겨찾기 목록, 마지막으로 듣던 곡과 재생 위치, 섞기·반복 설정을 기기의 앱 전용 저장 영역에만 저장합니다.

이 정보는 사업자나 제3자에게 전송되지 않으며, 앱을 삭제하면 함께 삭제됩니다.

4. 안드로이드 자동 백업 고지

전축은 안드로이드 표준 자동 백업(Auto Backup)을 허용합니다. 이용자가 기기 설정에서 백업을 켜 둔 경우, 안드로이드가 앱 설정(즐겨찾기·이어 듣기 정보)을 이용자 본인의 Google 계정 백업에 포함시킬 수 있으며, 기기 변경 시 복원에 사용됩니다. 이 백업은 이용자 본인의 계정에 속하며 Vravio Inc는 접근할 수 없습니다. 원하지 않으시면 기기의 설정 → Google → 백업에서 끌 수 있습니다.

5. 권한과 사용 목적

  • 음악 및 오디오 / 저장공간 읽기(READ_MEDIA_AUDIO, 안드로이드 12 이하 READ_EXTERNAL_STORAGE) — 기기에 저장된 음악 파일을 찾아 재생하는 용도로만 사용합니다.
  • 알림(POST_NOTIFICATIONS) — 재생 중인 곡과 재생·멈춤·다음 단추를 알림창과 잠금화면에 표시합니다.
  • 백그라운드 재생(FOREGROUND_SERVICE, FOREGROUND_SERVICE_MEDIA_PLAYBACK, WAKE_LOCK) — 화면을 끄거나 다른 앱을 써도 노래가 이어서 나오게 합니다.
  • 네트워크 상태 확인(ACCESS_NETWORK_STATE) — 재생 라이브러리(AndroidX Media3)가 자동으로 추가하는 권한입니다. 앱에는 인터넷 권한이 없으므로 이 권한으로 데이터를 보내거나 받지 않습니다.

6. 광고 및 추적

광고를 표시하지 않습니다. 광고 SDK, 분석 SDK, 크래시 리포팅 SDK를 포함하지 않으며 Android 광고 ID를 사용하지 않습니다.

7. 아동의 개인정보

전축은 만 13세 미만 아동을 대상으로 하지 않으며, 어떤 연령의 이용자로부터도 개인정보를 수집하지 않습니다.

8. 정보주체의 권리 및 데이터 삭제 방법

전축의 데이터는 전부 이용자 기기에 있으므로 이용자가 직접 즉시 삭제할 수 있습니다.

  • 전체 삭제 — 앱 삭제 시 로컬 데이터 전부 삭제
  • 앱 유지하며 삭제 — 기기의 설정 → 애플리케이션 → 전축 → 저장공간 → 데이터 삭제
  • 음악 파일 — 앱을 삭제해도 이용자의 음악 파일은 그대로 남습니다
